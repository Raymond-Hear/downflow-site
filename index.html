三步开始守护

先在 Edge 中开始下载，再打开 DownFlow。

  1. 01

    打开扩展

    使用发起下载时的同一个 Edge 配置文件。点击工具栏的拼图按钮，打开「下载续航 - DownFlow」。

  2. 02

    选中一条下载

    核对文件名、开始时间和进度，点「开始守护」。已暂停且可以恢复时，点「恢复并守护」。

  3. 03

    保持 Edge 运行

    看到「守护中」就可以关闭弹窗。保持 Edge 运行、电脑联网且不休眠。

保留原下载记录和未完成文件。 想把任务交回给 Edge，点击「停止守护」。现有下载会继续由 Edge 管理。

安装与更新

适用于从 ZIP 加载的本地扩展。

首次安装

  1. 解压安装 ZIP，找到直接包含 manifest.json 的文件夹。
  2. 在 Edge 地址栏打开 edge://extensions。
  3. 开启「开发人员模式」，点「加载解压缩的扩展」，选择第 1 步的文件夹。

有项目仓库访问权限时，也可下载源码 ZIP。解压后选择 extension 文件夹。

更新已安装的版本

  1. 如果正在守护，先点「停止守护」。
  2. 用新版 ZIP 中的文件更新原扩展目录，保留原目录路径。
  3. 回到扩展管理页，在 DownFlow 卡片上点「重新加载」，然后打开弹窗核对版本。

通过商店安装的版本，由 Edge 管理更新。

常见问题

找不到刚才下载的那条任务？

按 Ctrl + J 打开当前 Edge 配置文件的下载页。找到原记录，能手动恢复的话先恢复，再回到 DownFlow 点刷新。

扩展会查看最近最多 200 条进行中记录和 200 条中断记录，并另行核对当前守护的任务。

为什么显示「需要处理」，或恢复后仍然停着？

续传取决于 Edge、下载服务器和原链接。链接到期、需要登录、磁盘空间不足或浏览器要求确认时，请回到 Edge 下载页处理。浏览器或服务器也可能要求重新开始传输。

显示 0 B 或大小未知时，请先核对原任务和文件。该数值来自 Edge 的记录。

守护期间为什么会短暂暂停？

开始守护或恢复后，DownFlow 可能会短暂暂停再继续同一任务，以维持后续恢复能力。如果你在 Edge 里主动暂停，DownFlow 会停止守护。

Edge 显示下载完成后，可以打开文件确认是否正常。压缩包可通过解压或测试完整性来检查。

怎么提供诊断或清除守护记录？

打开「诊断与本地记录」。点击「复制诊断」并确认后，可查看和分享版本、浏览器信息及任务状态。诊断会省略文件名、完整链接、目录和 Cookies。

停止守护后，点击「清除本地守护记录」。Edge 下载历史和本地文件会保留。查看隐私说明
